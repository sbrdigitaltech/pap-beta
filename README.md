# pap-beta

**Beta preview builds of [papindia.in](https://papindia.in)** — generated,
already-public HTML only; no sources, no secrets.

Every push to `main` here is served by GitHub Pages at
**https://sbrdigitaltech.github.io/pap-beta/** within about a minute. Each
previewed page carries a "Beta preview — not live on papindia.in" banner and a
noindex tag, so it can't be confused with (or indexed against) the live site.

Publishing is automated from the private source repo by
`build/publish-beta.sh` — see `AGENTS.md` there. Do not edit by hand.
